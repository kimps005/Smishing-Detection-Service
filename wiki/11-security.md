# 보안 및 개인정보

## 애플리케이션 보호

- 이미지 크기·픽셀·텍스트 길이·URL 수를 제한합니다.
- 비용이 큰 분석 경로에 IP·경로별 요청 제한을 적용합니다.
- 분석 작업을 별도 작업자 풀에서 실행하고 취소 ID를 지원합니다.
- 관리자 로그는 `Authorization: Bearer <ADMIN_TOKEN>`을 검증합니다.

## URL 요청 보호

URL 요청 전과 리다이렉트마다 공용 주소인지 확인합니다. 로컬·사설·링크-로컬·예약 IP, `localhost`, 인증정보가 포함된 URL, HTTP(S) 이외의 스킴은 거부합니다.

## DB 연결 보호

`db_config.py`는 `DB_SSL_CA`가 지정된 경우 해당 CA를 사용합니다. `DB_SSL_VERIFY=1`이 기본이며, 인증서 검증을 끄는 설정은 로컬 테스트 외에는 사용하지 않는 것을 전제로 합니다.

## 개인정보 취급 주의

문자와 캡처 이미지에는 전화번호, 이름, 계좌 정보, 인증번호가 포함될 수 있습니다.

- 운영 로그는 필요한 범위만 저장하고 보존 기간을 정합니다.
- 외부 Gemini·VirusTotal 요청에 전송되는 데이터를 사전에 검토하고 적절한 동의를 받습니다.
- API 키·DB 비밀번호·관리자 토큰을 코드나 `.env` 커밋에 포함하지 않습니다.
- 피드백 첨부 이미지의 접근 권한과 삭제 절차를 운영 환경에서 정합니다.

## 판단의 한계

위협 피드 미등재나 낮은 점수는 안전을 보증하지 않습니다. 분류 신뢰도는 스미싱 확률이 아니며, 계정 차단·결제 중단·법적 판단 같은 자동 조치의 단독 근거로 사용해서는 안 됩니다.
