# URL 보안 분석

## 검사 순서

`server/url_analyzer.py`는 여러 URL을 받아 가장 높은 위험 신호를 중심으로 `P_URL`을 계산합니다.

1. URL 형식과 공용 인터넷 주소 여부 검증
2. 최대 5회 리다이렉트 추적 및 최종 URL·도메인 확인
3. Phishing.Database와 URLhaus 피드 대조
4. 최종 도메인의 VirusTotal 조회
5. WHOIS 생성일·도메인 연령 확인
6. URL 구조 특징 10종 계산
7. 최종 URL의 APK 다운로드 유도 확인
8. 피드·평판·특징·도메인·APK 신호를 결합

## URL 구조 특징

URL 길이, 도메인·경로 길이, 서브도메인 수, 특수문자 수, 숫자 비율, IP 직접 사용, 의심 키워드, 단축 URL, 의심 TLD를 검사합니다.

## 안전한 네트워크 요청

URL을 요청하기 전과 리다이렉트마다 다음 대상을 거부합니다.

- `localhost` 및 `.localhost`
- 사설·루프백·링크-로컬·멀티캐스트·예약·미지정 IP
- 사용자명·비밀번호가 포함된 URL
- HTTP(S)가 아닌 스킴

이 검사는 URL 분석기가 내부 네트워크 주소를 요청하는 SSRF 위험을 낮추기 위한 것입니다.

## URL 점수 해석

피드에 등재된 URL은 높은 우선순위로 반영됩니다. VirusTotal에서 안전이 확인된 경우 정상 서비스의 긴 URL·단축 URL·신생 도메인에 대한 일부 패널티를 완화합니다. 반대로 VirusTotal 미등록은 안전 판정이 아니라 정보 부족으로 취급될 수 있습니다.

URL 검사 결과가 없다는 사실만으로 링크가 안전하다는 의미는 아닙니다.
