# 전체 아키텍처

## 구성 요소

```text
┌───────────────┐     HTTP/JSON·multipart     ┌────────────────────┐
│ Flutter 앱     │ ─────────────────────────▶ │ FastAPI API         │
│ Streamlit UI   │                            │ server/main.py      │
│ FastAPI 웹     │                            └─────────┬──────────┘
└───────────────┘                                      │
                                                       │
       ┌──────────────────────┬────────────────────────┼─────────────────────┐
       ▼                      ▼                        ▼                     ▼
  PaddleOCR/pyzbar       predictor.py            url_analyzer.py        Gemini API
  텍스트·QR 추출          KLUE/BERT 분류          URL 평판·도메인 검사      문맥·Vision
       └──────────────────────┴────────────────────────┴─────────────────────┘
                                                       │
                                                       ▼
                                             MySQL / Aiven (선택)
                                             로그·피드백·URL 랭킹
```

## 요청 처리 방식

1. FastAPI lifespan에서 분류 모델을 준비하고, DB가 설정되어 있으면 URL 카운터를 읽습니다.
2. 이미지 요청은 크기·픽셀·파일 형식을 검사한 뒤 전용 작업자 스레드에서 OCR·QR·분석을 수행합니다.
3. 텍스트 요청은 입력 정규화와 URL 추출 후 같은 통합 분석 함수를 사용합니다.
4. 결과를 DB 로그에 기록하고 위험 URL이면 누적 랭킹을 갱신합니다.
5. 클라이언트에는 점수, 등급, 카테고리, 탐지 근거를 JSON으로 반환합니다.

## 백그라운드 작업

- 위협 피드는 서버 시작 시와 6시간마다 갱신됩니다.
- URL 랭킹 상위 항목은 주간 재검사를 통해 현재 피드·VirusTotal 상태를 다시 확인합니다.
- 분석 작업은 `ThreadPoolExecutor`로 처리하며 요청의 `X-Analysis-ID`를 사용해 협력 취소를 지원합니다.

## 점수 신호

| 신호 | 의미 |
| --- | --- |
| `P_NLP` | 위험 키워드 및 카테고리 패턴으로 계산한 텍스트 신호 |
| `P_URL` | URL 피드·평판·구조·도메인 연령·APK 신호의 결합 점수 |
| `P_Gemini` | 텍스트 문맥에 대한 Gemini 위험 점수 |
| `P_VLM` | 이미지 시각 분석에 대한 Gemini Vision 점수 |
| `final` | 입력 유형과 사용 가능한 신호에 따라 결합한 최종 점수 |
