# 프로젝트 개요

## 프로젝트 목적

CatchSmishing은 사용자가 받은 문자 메시지를 텍스트, 캡처 이미지 또는 QR 코드 형태로 입력하면 여러 독립적인 신호를 결합해 스미싱 위험도를 안내하는 서비스입니다.

단일 키워드나 단일 AI 모델에 의존하지 않고 다음 정보를 함께 사용합니다.

- 이미지 입력: OCR 텍스트와 QR URL
- 텍스트 입력: 본문과 포함 URL
- 한국어 문자 카테고리 분류
- 긴박감·위협·행동 유도 패턴
- URL 리다이렉트·위협 피드·VirusTotal·WHOIS·APK 신호
- Gemini 텍스트 문맥 및 Gemini Vision 시각 신호

## 제공 클라이언트

| 클라이언트 | 역할 | 진입점 |
| --- | --- | --- |
| FastAPI 웹/API | 분석 요청, 결과 페이지, 피드백, 랭킹, 관리자 로그 | `server/main.py` |
| Streamlit 운영 UI | 이미지·텍스트·QR 입력과 결과 확인 | `server/app.py` |
| Flutter 모바일 앱 | 이미지 선택, 텍스트 공유, QR 카메라 스캔, 결과 표시 | `lib/main.dart` |

## 사용자에게 반환하는 결과

- 최종 위험 점수와 `Danger`·`Warning`·`Safe`·`Unknown` 등급
- 문자 카테고리 및 분류 신뢰도
- OCR 또는 입력 텍스트와 추출 URL
- 위험 키워드 및 텍스트·URL 탐지 근거
- Gemini 문맥·Vision 분석 사유(사용 가능한 경우)
- 위험 URL 랭킹(위험 URL 또는 피드 등재 URL인 경우)

## 현재 서비스 범위

- 별도 사용자 로그인 없이 분석을 시작할 수 있습니다.
- 관리자 분석 로그는 `ADMIN_TOKEN`으로 보호된 `/admin/logs`에서 확인합니다.
- 피드백 및 URL 랭킹은 MySQL 연결이 설정된 경우 저장됩니다.
- 사용 가능한 보조 API가 없더라도 기본 OCR·분류·규칙·URL 분석 결과는 가능한 범위에서 반환합니다.
