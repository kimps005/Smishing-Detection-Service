# 피드백 개선

## 사용자 피드백 입력

`POST /feedback`는 다음 정보를 저장합니다.

- 현재 표시된 등급: `given_grade`
- 사용자가 정정한 등급: `correct_grade`
- 정정 사유: `reason`
- 관련 문자: `text_content`
- 선택적 캡처 이미지: `image`

허용 등급은 `Danger`, `Warning`, `Safe`이며, 피드백 이미지도 형식·크기·이미지 디코딩 검사를 거칩니다.

## 운영 화면

Streamlit의 피드백 화면은 API에 피드백을 제출하고, `/top-urls?limit=50`으로 위험 URL 랭킹을 조회합니다. 관리자는 `/admin/logs`에서 입력 유형, 등급, 점수, 카테고리, 신호별 점수, 추출 텍스트, URL, 일부 Gemini 사유를 확인할 수 있습니다.

## 개선에 활용할 수 있는 신호

분석 로그와 피드백에는 오탐·미탐 검토에 필요한 결과 등급, 카테고리, `P_NLP`, `P_URL`, Gemini/Vision 점수, 위험 키워드, URL 근거가 기록됩니다. 이를 바탕으로 규칙·모델·프롬프트를 검토할 수 있지만, 재학습 데이터로 사용하기 전에는 개인정보 제거와 데이터 사용 동의를 별도로 확인해야 합니다.

현재 저장소에는 피드백을 자동으로 모델 재학습에 반영하는 파이프라인은 포함되어 있지 않습니다.
